EX:MAZE 축제용 시간 보상 기준

보상은 5개 스테이지를 모두 완주했을 때만 결과 화면에 표시됩니다.
- GOLD: 3분 00초 이내 — 봉지 과자 1개
- SILVER: 3분 초과, 5분 00초 이내 — 박스 과자 1개
- BRONZE: 5분 초과 — 참가상 사탕

시간은 공식 도전 시작부터 5단계 최종 클리어까지 측정합니다.
GitHub Pages 정적 사이트이므로 기록/보상 정보는 해당 브라우저의 로컬 저장소에 저장됩니다.
실제 보상 지급은 부스 진행자가 결과 화면을 확인한 뒤 진행하세요.
시간 기준은 실제 참가자 기록을 확인한 뒤 필요하면 조정하는 것을 권장합니다.

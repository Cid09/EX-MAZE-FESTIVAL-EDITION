EX:MAZE FESTIVAL - SOLO CAMERA FOLLOW FIX

This build restores the EX:MAZE solo-style camera-follow view:
- The player stays near the center of a 21-cell viewport.
- The maze scrolls smoothly as the player moves.
- Existing 13 stages, name entry, timer, grade/reward result, local leaderboard, and original BGM files are retained.
- Keyboard controls and existing touch controls are retained.

GitHub Pages deployment:
1. Extract this ZIP.
2. Upload the contents of EX-MAZE-FESTIVAL-GITHUB to the repository root (index.html and the MP3 files must remain together).
3. Commit the changes and wait for GitHub Pages to redeploy.

Leaderboard records are local to that browser/device. The code was checked for JavaScript syntax and the ZIP was checked for integrity. It has not been physically tested on every browser/device.

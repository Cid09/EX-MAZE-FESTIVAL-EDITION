EX:MAZE 청람제 체크포인트 업데이트

적용 사항
- 5개 고정 스테이지마다 순서형 체크포인트 3개를 배치합니다.
- 체크포인트는 해당 스테이지의 출발점-출구 최단 경로 위에 배치되므로 모두 도달 가능한 위치입니다.
- 현재 목표 체크포인트는 밝은 청록색, 통과한 체크포인트는 초록색으로 표시합니다.
- 상단 HUD에 CHECKPOINT 진행 상황을 표시합니다.
- 3개 체크포인트를 모두 밟기 전에는 출구에 도착해도 스테이지가 클리어되지 않습니다.
- 3개를 모두 밟으면 출구가 초록색으로 바뀌며, 출구에 도착하면 기존 스테이지 클리어/전환 흐름을 사용합니다.
- 기존 음악 파일, 시작 화면, 리더보드, 타이머, 보상 코드는 유지했습니다.

설치
1. 압축을 풉니다.
2. EX-MAZE-FESTIVAL-GITHUB 폴더 안의 파일을 GitHub Pages 저장소 루트에 올립니다.
3. index.html과 MP3 파일들을 같은 폴더에 둡니다.

검증 상태
- 인라인 JavaScript 구문 검사를 통과했습니다.
- Chromium 헤드리스 DOM 로드 테스트를 수행했습니다.
- 실제 참가자 플레이로 2분 30초~4분 완주 시간이 나오는지는 별도 플레이 테스트가 필요합니다.
